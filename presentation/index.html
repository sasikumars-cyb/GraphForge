Engineering Memory

Append-only. Never edited. Never lost.

  • Every hypothesis, validation, correction permanently retained
  • "Current" state = latest version, computed at read time
  • A repeat run appends a new row — never overwrites
  • Postgres, not Neo4j — this is the real source of truth
Postgres — knowledge_relationships

-- append-only: no UPDATE path exists
-- on this table, anywhere in the codebase
SELECT relationship_key, confidence_state,
       sequence, created_at
FROM knowledge_relationships
WHERE relationship_key = 'order-service:CALLS:payment-service'
ORDER BY sequence DESC
LIMIT 1;   -- "current" = latest, not stored
Say: "Nothing here is ever UPDATEd. That single fact is what makes real confidence history possible."
Key points: The `sequence` column exists because Postgres timestamps in the same transaction can collide — a real bug this caught.
Transition: "But how do we decide what's worth remembering in the first place?"
Expect: "Doesn't this grow forever?" → Yes, by design — only raw evidence blobs are archivable; hypothesis/validation/confidence history never is.

Confidence Engine

Six states. Never a bare float.

VERIFIED HIGHLY LIKELY LIKELY CANDIDATE CONFLICTING REJECTED

  • Verified needs ≥2 independent confirming sources — never one LLM alone
