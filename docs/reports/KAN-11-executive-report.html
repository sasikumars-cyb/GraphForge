KAN-44 (new) Engineering Sessions have no ownership check

All 27 endpoints on engineering_sessions.py — any authenticated user can read/mutate any Session, including another user's evidence, hypotheses, and decisions. EngineeringSession has no user_id column, and RFC-001 never states whether Sessions are meant to be private or a shared team workspace. Filed rather than guessed at; blocked on that decision.

FILED

KAN-45 (new) Cross-tenant Neo4j topic-peer leak

find_cross_repository_topic_peers has no tenant filter at the graph-query level across 4 call sites — a component from another tenant's repository can appear in a topic-peer response when Kafka topic names collide. The fix needs the caller's legitimate repository scope threaded through each call site differently; couldn't be safely implemented or verified without a live Neo4j, so it's documented in full rather than attempted blind.
